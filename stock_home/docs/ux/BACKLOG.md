# stock_home UI backlog (UX wireframes)

Single source of truth for the `stock-home-ui` agent (`/implement-ui`).
Designs: `stock_home/ux-proposals/<N> STOCK_HOME_*.md` (wins on conflicts) and `stock_home/ux-proposals/Design_UI_images/*.png` (visual reference).

Status legend: `[ ]` todo · `[~]` in progress · `[x]` done · `[!]` blocked (reason in Notes) · `[-]` dropped (reason in Notes)

Rules:
- Work top to bottom; an item may start only when every ID in **Deps** is `[x]` or `[-]`.
- One item = one local commit (`git log --grep U##`).
- Wireframe sample values are placeholders; missing data → `—` or an explicit "unavailable" panel, never fake values.
- New data comes from stock_home Go endpoints backed by Prometheus, Alertmanager or OpenBB; `/api/v1` shapes are only extended, never changed.

Decisions:
- Dark theme by default; light/system selectable in Settings.
- The sidebar shell replaces `NavTabs`; `/analyst` and `/openbb` stay reachable (Stock Explorer detail links to `/analyst`).
- Persistence (watchlist groups, settings) uses browser storage until the SQLite store (openbb-parity F003) exists.
- Alertmanager has no acknowledge/resolve: "Acknowledge"/"Silence" create a silence after confirmation; "Resolve" is not offered.

Design reconcile (U00, recorded after U01–U13 shipped; describes what is built):
- **Shell variants.** MDs 1–6 share one detailed shell (13-item sidebar with Alerts badge and bottom Market Status card; header with search, IST clock, Live Market, settings, bell, avatar; footer `stock_home | version · Data via … | NSE | ● Live`). MDs 7–9 show a minimal header ("Market status / last updated · Profile") and say to reuse the shell; MDs 10–11 only say "reuse". MD 12 and the Settings PNG show a 10-item sidebar (no Market Overview, Dashboards, Grafana), a sidebar Quick Links section, help icon, `Ctrl+K` hint and a footer with "Connected to / Last Updated / Documentation · GitHub · Support". Decision: the MD 1–6 shell is canonical and defined once (`web/components/shell/nav.ts`); MD 7–12 shell details are not applied. No sidebar Quick Links (Prometheus, Alertmanager and OpenBB are in-app pages with "Open full … UI" links; Grafana is an external nav item; Home keeps its Quick Links panel). No help icon or Documentation/GitHub/Support links (no configured destinations).
- **Bell and sidebar Market Status card.** Both are in MDs 1–6 but not in every PNG; kept per MD. The bell shows the active-alert count and opens `/alerts`.
- **Theme.** MDs 1–6 specify dark; MD 12 and the Settings PNG show light with "System" selected. Dark is the default, and Light/Dark/System is selectable in Settings.
- **Stock Explorer.** MD 7 is a discovery page (search, filters, results, detail). `Stock_Explorer_UI.png` shows an unrelated "Stock Exporter" operations page (exporter status, ticks/API/latency charts, tracked-symbol admin, logs, restart). The MD was built and the PNG is not used. An exporter operations page would need its own wireframe and item; it is not added.
- **Settings.** MD 12 and `Settings_UI.png`/`Settings_UI_dark.png` agree on the seven tabs and the nine General cards; they differ only in the shell (above). The U13 note's claim that the PNG has different cards and tabs is wrong. Controls without a backing behaviour are marked fixed or unavailable instead of copying the PNG's working-looking values (30-day retention, notification toggles, "Configured" badges).
- **Dashboards vs Home.** MD 8 "Dashboard" (index, watchlist and alert cards, market trend, watchlist snapshot, alerts, top movers, optional service status) is the Home page (`/`, MD 1) and is not built twice. `/dashboards` lists Grafana dashboards (U09). The optional service-status strip is not added to Home (not in MD 1 or Home_UI.png). Service health is in Settings › Integrations (Test) and on the Prometheus and Alertmanager pages.
- **Panels and fields without a data source**, shown as `—`, unavailable or relabelled instead of faked:
  - Company names: the exporter has none. They appear only where OpenBB answers `equity/profile`.
  - Market cap: none, so heatmaps are sized by constituents or equal tiles and there is no "Large Cap" tag.
  - NIFTY 50 membership: none, so lists say "core equities".
  - Index volume: none, so chart bars show core-equity volume.
  - News sentiment: none, so impact dots are neutral.
  - Alert value and threshold: need `value`/`threshold` rule annotations.
  - User identity: none, so the avatar is generic and silences are created by `stock_home`.
  - Notifications: stock_home sends none; Alertmanager receivers do.
  - Alert-rule creation and Set Alert: rules live in Prometheus files.
  - Holiday calendar: only when `--market.holidays-file` is set.
  - OpenBB panels: only when `--openbb.url` is set.
- **Deployment gap.** The default `--market.indices` includes NIFTY NEXT 50, but Helm `stockHome.indices` in `deploy/` does not, so that card shows `—` there.
